Практична робота: Розробка Python-скрипта для моніторингу ресурсів вбудованої системи Linux
Мета роботи: Опанувати взаємодію високорівневої мови Python із системними файлами ОС Linux (Debian/Ubuntu Server) та апаратними інтерфейсами одноплатного комп'ютера.
Основне завдання: Розробити скрипт, який працює у фоновому режимі, збирає телеметрію вбудованої системи, зберігає дані та апаратно реагує на критичні зміни стану.

#Опис

Програма отримує інформацію безпосередньо із системних файлів ядра Linux, обчислює показники використання ресурсів та автоматично зберігає результати вимірювань у CSV-файл.

**Основні можливості:**
- Вимірювання температури процесора через `/sys/class/thermal/thermal_zone0/temp`.
- Обчислення завантаження CPU за даними `/proc/stat`.
- Визначення використання оперативної пам'яті за даними `/proc/meminfo`.
- Збереження показників у CSV-файл з часовими позначками.
- Налаштування інтервалу та кількості вимірювань.
- Виведення попередження при перевищенні температури 60 °C.
- Автоматичний запуск та перезапуск програми за допомогою `systemd`.

# Структура проєкту

- `sys_monitor.py` — основний Python-скрипт для збору телеметрії.
- `telemetry.csv` — приклад результатів моніторингу.
- `monitor.service` — конфігураційний файл служби systemd.
- `README.md` — опис проєкту та інструкція з використання.

# Системні вимоги

Для роботи програми необхідні:

- Операційна система Linux (Debian або Ubuntu Server).
- Python 3.
- Доступ до системних файлів `/proc/` та `/sys/`.
- Підсистема `systemd` для автоматичного запуску.

# Запуск програми

**1. Перевірка наявності Python**

Відкрийте термінал Linux та виконайте команду:

`python3 --version`

Якщо Python встановлений, термінал відобразить його версію.

**2. Перехід до каталогу проєкту**

Перейдіть у папку, де знаходиться файл `sys_monitor.py`, за допомогою команди `cd`.

**3. Запуск моніторингу**

`python3 sys_monitor.py`

За замовчуванням програма виконуватиме вимірювання кожні 5 секунд без обмеження кількості записів.

Для виконання 20 вимірювань:

`python3 sys_monitor.py --count 20 --interval 5 --output telemetry.csv`

Після завершення вимірювань результати будуть записані у файл `telemetry.csv`.

**Параметри запуску:**

- `--count` — кількість вимірювань (0 — необмежена).
- `--interval` — інтервал між вимірюваннями в секундах.
- `--output` — назва або шлях до CSV-файлу.
- `--temp-path` — шлях до системного файлу температури.

Для дострокового завершення програми використовуйте `Ctrl+C`.

## Формат результатів

Файл `telemetry.csv` містить чотири стовпці:

- `Timestamp` — дата й час вимірювання.
- `Temp` — температура процесора, °C.
- `CPU_Load` — завантаження процесора, %.
- `RAM_Usage` — використання оперативної пам'яті, %.

Якщо системний файл температури недоступний, замість числового значення записується `N/A`.

## Автоматичний запуск через systemd

Для безперервної роботи у фоновому режимі використовується файл `monitor.service`.

**1. Створіть каталог програми:**

`sudo mkdir -p /opt/sys-monitor`

**2. Скопіюйте Python-скрипт:**

`sudo cp sys_monitor.py /opt/sys-monitor/`

**3. Скопіюйте конфігураційний файл служби:**

`sudo cp monitor.service /etc/systemd/system/`

**4. Оновіть конфігурацію systemd:**

`sudo systemctl daemon-reload`

**5. Увімкніть автозапуск і запустіть службу:**

`sudo systemctl enable --now monitor.service`

**6. Перевірте стан служби:**

`sudo systemctl status monitor.service`

**7. Перегляньте повідомлення програми:**

`sudo journalctl -u monitor.service -f`

**8. Для зупинення служби виконайте:**

`sudo systemctl stop monitor.service`

Під час роботи через systemd результати автоматично зберігаються у файлі:

`/var/lib/sys-monitor/telemetry.csv`

Служба налаштована на повторний запуск через 5 секунд у разі аварійного завершення програми.

## Особливості роботи

Моніторинг виконується шляхом періодичного зчитування системних файлів Linux. Дані завантаження процесора визначаються за різницею двох послідовних вимірювань, а використання оперативної пам'яті обчислюється на основі параметрів `MemTotal` і `MemAvailable`.

Температурне попередження формується, якщо температура процесора перевищує встановлений поріг 60 °C.

Програму можна використовувати для навчального дослідження ресурсів вбудованих Linux-систем і збирання статистичних даних під час їхньої роботи.

## Перевірка температурного попередження

Для перевірки спрацювання температурного попередження без фактичного нагрівання процесора можна використати тестовий файл із заданим значенням температури.

### 1. Створення тестового файлу

У терміналі Linux виконайте команду:

`echo 61000 > /tmp/test_temp

Значення `61000` відповідає температурі **61 °C**, оскільки програма ділить отримане значення на 1000.

### 2. Запуск програми з тестовими даними

`python3 sys_monitor.py --temp-path /tmp/test_temp --count 3 --interval 1 --output test.csv

Параметри запуску:
- `--temp-path` — шлях до тестового файлу температури.
- `--count 3` — виконання трьох вимірювань.
- `--interval 1` — інтервал між вимірюваннями 1 секунда.
- `--output test.csv` — файл для збереження результатів.

### 3. Перевірка перевищення температурного порога

При температурі **61 °C** програма виведе повідомлення:

Temp: 61.0 °C
УВАГА: перевищено температурний поріг!

### 4. Перевірка за нормальної температури

Для встановлення температури **59 °C** виконайте:

`echo 59000 > /tmp/test_temp

Повторно запустіть програму:

`python3 sys_monitor.py --temp-path /tmp/test_temp --count 3 --interval 1 --output test.csv

Оскільки температура нижча за встановлений поріг **60 °C**, попередження не з'явиться.
